## Props

| Prop | Type | Description |
| :--- | :--- | :--- |
| `title` | `string` | Optional. The main heading for the pricing section. Default: `"Simple pricing for\nevery stage of growth."` |
| `subtitle` | `string` | Optional. The descriptive text under the main heading. Default: `"Choose the plan that fits your team's current needs and scale effortlessly as you grow."` |
| `tiers` | `PricingTier[]` | Optional. An array of pricing tier objects to display. Defaults to a standard 3-tier setup. |
| `...rest` | `any` | The component does not spread extra props to the wrapper element currently. |

### PricingTier

| Prop | Type | Description |
| :--- | :--- | :--- |
| `name` | `string` | Required. The name of the tier (e.g. "Pro"). |
| `description` | `string` | Required. A short description for the tier. |
| `priceMonthly` | `string \| number` | Required. The price per month. |
| `priceAnnually` | `string \| number` | Required. The equivalent monthly price when billed annually. |
| `billedAnnuallyText` | `string` | Optional. Text to display below the annual price (e.g. "Billed $120 yearly"). |
| `features` | `PricingFeature[]` | Required. An array of feature objects `{ name: string }`. |
| `ctaText` | `string` | Required. The text for the call-to-action button. |
| `isPopular` | `boolean` | Optional. Whether this tier should be highlighted as popular. |
