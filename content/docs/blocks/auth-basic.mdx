### Props

| Prop | Type | Description |
|---|---|---|
| `brandName` | `string` | **Optional.** The brand title displayed in the header badge. Default: `"Jack UI"`. |
| `logo` | `React.ReactNode` | **Optional.** Custom logo React element. If omitted, renders a default clean shield badge. |
| `dotColorLight` | `string` | **Optional.** Border and grid dot matrix color for light mode. Default: `"rgba(0, 0, 0, 0.22)"`. |
| `dotColorDark` | `string` | **Optional.** Border and grid dot matrix color for dark mode. Default: `"rgba(255, 255, 255, 0.35)"`. |
| `showSocialLogin` | `boolean` | **Optional.** Toggles display of social auth provider buttons (Google, GitHub). Default: `true`. |
| `className` | `string` | **Optional.** Additional Tailwind CSS classes (e.g. background override, full width/height). |
| `style` | `React.CSSProperties` | **Optional.** Inline CSS styles (custom background gradients, full viewport sizing). |
| `...props` | `React.ComponentPropsWithoutRef<"div">` | **Optional.** Any extra HTML `div` attributes spread onto the outer container. |
