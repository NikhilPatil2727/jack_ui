### Props

| Prop | Type | Description |
|------|------|-------------|
| `children` | `React.ReactNode` | **Optional.** The content to render inside the button. Default: `"Initialize App"`. |
| `variant` | `"dark" \| "light" \| "coral" \| "neon"` | **Optional.** Sizing variant adjusting the color theme. Default: `"dark"`. |
| `tag` | `string` | **Optional.** A small text tag displayed alongside the children text. |
| `...props` | `React.ButtonHTMLAttributes<HTMLButtonElement>` | **Optional.** Any additional standard HTML button element properties (e.g. `onClick`, `disabled`, `className`) can be passed and are spread onto the button. |
