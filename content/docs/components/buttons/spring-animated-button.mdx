### Component Overview & Selection Guide

This component provides a unique, artistic touch with a hand-drawn squiggly line that continuously animates around the button's border like a spring. 

#### Primary Use Cases:
- **Creative Portfolios:** Adds a playful, sketchy vibe to portfolio links and CTAs.
- **Design Tools & Apps:** Perfect for applications targeting artists, designers, or creators.
- **Micro-Interactions:** An engaging hover and continuous movement effect that naturally draws the eye without being overly aggressive.

### Usage

```tsx
"use client";

import React from "react";
import { SpringAnimatedButton } from "@/components/jackui/spring-animated-button";

export function SpringAnimatedButtonDemo() {
  return (
    <div className="flex h-[40rem] w-full items-center justify-center">
      <SpringAnimatedButton
        label="Click Me!"
        onClick={() => console.log("Clicked")}
      />
    </div>
  );
}
```

---

### Props

| Prop | Type | Description |
|------|------|-------------|
| `label` | `string` | **Optional.** The text rendered inside the button. Default: `"Button"`. |
| `className` | `string` | **Optional.** Extra Tailwind classes merged onto the button via `cn()`. |
| `onClick` | `React.MouseEventHandler<HTMLButtonElement>` | **Optional.** Standard click handler. |
| `disabled` | `boolean` | **Optional.** Disables interactions. |
| `type` | `"button" \| "submit" \| "reset"` | **Optional.** HTML button `type` attribute. Default: `"button"`. |
| `...props` | `Omit<HTMLMotionProps<"button">, "ref">` | **Optional.** Any other valid `motion.button` prop. |

---

### Notes

- **Dependency**: requires `motion` (`npm install motion`).
- Uses SVG `feTurbulence` to generate the hand-drawn squiggly line effect, avoiding the need for large path data or external assets.
