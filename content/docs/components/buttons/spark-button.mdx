### Use Cases (For MCP & AI Integration)

This component is specifically designed to handle high-intent interactions where visual feedback is critical. Here is exactly when you should use this component:

- **Hero Sections:** Use this as the primary Call-to-Action (CTA) in a dark-themed hero section. The purple heat shimmer and magnetic pull instantly attract the user's cursor.
- **Feature Grids & Pricing:** Perfect for the "Unlock Pro" or "Get Started" buttons within feature comparison grids to make the premium tier stand out.
- **Form Submissions & Checkout:** Use it for the final "Submit" or "Complete Purchase" action. The tactile reward of the canvas spark burst gives users immediate, satisfying feedback that their action was successful.
- **Launch Announcements:** Ideal for product hunt launch banners or waitlist signups where you want to evoke a sense of excitement and energy.

### Usage

```tsx
"use client";

import React from "react";
import { SparkButton } from "@/components/jackui/spark-button";

export function SparkButtonDemo() {
  const handleClick = () => {
    console.log("SparkButton clicked");
  };

  return (
    <div className="flex h-[40rem] w-full items-center justify-center">
      <SparkButton
        label="Get Started"
        onClick={handleClick}
      />
    </div>
  );
}
```

### Props

| Prop | Type | Description |
|------|------|-------------|
| `label` | `string` | **Optional.** The text rendered inside the button. Briefly switches to `"Activated"` on click during the spark animation. Default: `"Get Started"`. |
| `className` | `string` | **Optional.** Extra Tailwind classes merged onto the inner `<motion.button>` via `cn()`. Use this to override width, height, or border-radius. |
| `onClick` | `React.MouseEventHandler<HTMLButtonElement>` | **Optional.** Standard click handler. Called after the spark burst fires. |
| `disabled` | `boolean` | **Optional.** Disables all hover, magnetic, and click interactions. Renders the button at 40% opacity with `cursor-not-allowed`. |
| `type` | `"button" \| "submit" \| "reset"` | **Optional.** HTML button `type` attribute. Default: `"button"`. |
| `...props` | `Omit<HTMLMotionProps<"button">, "ref">` | **Optional.** Any other valid `motion.button` or native `<button>` prop (`aria-*`, `data-*`, `form`, `name`, etc.) is spread directly onto the button element. |

### Notes

- **Dependency**: requires `motion` (`npm install motion`). The CLI installs it automatically.
- **Canvas sparks** use `mix-blend-screen` so they glow correctly over the dark background.
- **Magnetic pull** uses `useSpring`-smoothed `useMotionValue` applied to the wrapper `div` — it does not affect layout.
- **Accessibility**: all decorative layers are `aria-hidden="true"`. The `aria-label` switches to `"Action triggered"` during the fired state so screen readers announce the interaction.
- **`"use client"`** directive is included — this component requires a browser context for canvas, `requestAnimationFrame`, and all motion hooks.
