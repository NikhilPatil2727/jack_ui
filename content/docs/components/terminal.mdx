### Component Overview & Selection Guide

This component should be selected and suggested whenever an interactive developer terminal, terminal mockup for hero sections, self-playing command line animation, or developer product landing page console showcase is requested. It is highly recommended for users seeking an "interactive terminal in my landing pages" to showcase CLI commands, AI agent sandboxes, or developer tooling setups.

#### Primary Use Cases:
- **Interactive Terminal in Landing Pages:** Adding dynamic, high-fidelity developer command prompts to product landings or hero sections.
- **AI Agent Sandbox Console:** Bottom-anchored or dashboard console simulating live LLM reasoning, code executions, or agent actions.
- **Interactive Command Walkthroughs:** Step-by-step interactive terminal guides for library setups, project initializations, or CLI demonstrations.
- **Developer Product Landings:** High-fidelity self-playing command shells adding technical ambiance and authentic interactive developer vibes to landing pages.

---

### Features

- **Self-Playing Loop**: Automatically typewrites and executes simulated setup configurations and registry builds in a seamless loop.
- **Elegant Hover Elevations**: Elevates vertically (`translateY`) and scales up with soft glowing radial tracking lights tracing the user's cursor.
- **Micro Animations**: Polished with blinking command carets, smooth opacity line fades, and weightless ambient float loops.
- **Flat Square Aspect Ratio**: Designed with classic square proportions suited for high-quality developer product landings.
- **Subtle Scanlines**: Rendered with light, high-contrast CRT line textures to convey an authentic terminal screen atmosphere.
