# NeuralCircuitOrchestrator

Displays a premium, animated Neural Circuit Grid that visually aggregates gateway sources.
`Card` `Animation` `SVG` `Premium`

## Props

| Prop | Type | Description |
| :--- | :--- | :--- |
| `className` | `string` | Optional. Custom Tailwind classes to apply to the root container. Default: `undefined` |
| `gatewayLabel` | `string` | Optional. Central gateway button text. Default: `"AGENT GATEWAY"` |
| `onGatewayClick` | `() => void` | Optional. Callback event triggered when the central gateway button is clicked. |
| `cards` | `OrchestratorCard[]` | Optional. Custom list of orchestrator cards to render. Defaults to a standard 3-card layout (React, Next.js, TanStack). |
| `onCardClick` | `(cardId: string) => void` | Optional. Callback event triggered when an individual card is clicked. Receives the `cardId` as an argument. |
| `...rest` | `React.HTMLAttributes<HTMLDivElement>` | Optional. Any standard HTML attributes (e.g. `style`, `id`, `aria-label`) are passed through to the root container `div`. |

### OrchestratorCard Type

| Property | Type | Description |
| :--- | :--- | :--- |
| `id` | `string` | Required. Unique identifier for the card and its connection track. |
| `title` | `string` | Required. Main title of the card. |
| `description` | `string` | Required. Text description explaining the card's purpose. |
| `href` | `string` | Optional. Action link target when the card is clicked. Default: `"#"` |
| `icon` | `React.ReactNode` | Optional. Custom element to render as the card's top icon. Falls back to a default `CognitiveIcon`. |
| `theme` | `"violet" \| "emerald" \| "rose"` | Optional. Selects the neon theme mapped for stroke glows and hover highlights. Default: `"violet"` |
